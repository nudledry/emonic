# Emonic

**Emonic** adalah aplikasi mobile yang berfungsi sebagai alat pencatatan energi listrik harian. Aplikasi ini membantu pengguna untuk memantau, mencatat, dan mengelola penggunaan energi listrik secara efisien setiap hari. Dikembangkan menggunakan Flutter dan terintegrasi dengan Firebase untuk autentikasi serta Cloud Firestore sebagai basis data utama.

## Fitur Utama

- **Pencatatan Energi Harian:** Mencatat penggunaan energi listrik setiap hari.
- **Manajemen Target Energi:** Menambah, mengedit, dan menghapus target penggunaan energi.
- **Autentikasi Lengkap:** Mendukung pendaftaran akun, login, logout, serta reset password menggunakan email atau akun media sosial.
- **Pengelolaan Profil:** Edit profil, ubah email, ubah password, dan pengaturan akun lainnya.
- **Halaman Pengaturan:** Termasuk kebijakan privasi, bantuan, dan informasi aplikasi.
- **Integrasi Firebase:** Semua data pengguna dan pencatatan energi tersimpan aman di Cloud Firestore.
- **Dukungan Local Storage:** Data target energi juga dapat disimpan secara lokal menggunakan SQLite.

## Teknologi yang Digunakan

- **Flutter & Dart**
- **Firebase Authentication**
- **Cloud Firestore**
- **SQLite (untuk penyimpanan lokal)**
- **Arsitektur BLoC** (Business Logic Component) untuk pemisahan logika aplikasi dan antarmuka pengguna

## Instalasi

Untuk menggunakan aplikasi Emonic, cukup unduh file APK yang tersedia dan lakukan instalasi pada perangkat Android:

1. **Unduh file APK**
   - Dapatkan file APK Emonic dari link berikut:  
     [Link Download APK](https://drive.google.com/file/d/1HyYF_UIMEgxyWyuGo0Mm-uTjoBsXa1IC/view?usp=sharing](https://drive.google.com/file/d/1x6O4U13ssOiUaABhQc5pMStL6SOWLjJD/view?usp=sharing)

2. **Instal aplikasi**
   - Buka file APK yang telah diunduh pada perangkat Android.
   - Jika muncul peringatan keamanan, aktifkan izin instalasi aplikasi dari sumber tidak dikenal pada pengaturan perangkat.
   - Ikuti instruksi hingga proses instalasi selesai.

3. **Buka aplikasi**
   - Setelah instalasi selesai, buka aplikasi Emonic dan lakukan pendaftaran atau login untuk mulai menggunakan fitur-fitur yang tersedia.

## Kontribusi

Kontribusi pada project ini meliputi pengembangan sistem autentikasi lengkap (login, sign up, logout, dan lupa password) dengan integrasi Firebase Authentication dan Firestore Database, penambahan fitur pencatatan penggunaan energi harian, serta pembuatan halaman pengaturan yang mencakup edit profil, ubah email, ubah password, kebijakan privasi, dan bantuan. Seluruh fitur diimplementasikan menggunakan arsitektur BLoC untuk memastikan pemisahan logika backend dan antarmuka pengguna.
